# My Blog - React + MUI Blog Application

A modern, responsive blog application built with React, TypeScript, and Material-UI (MUI). Features include a blog post grid, post creation dialog, and state management with Zustand.

**Live Demo:** [blog-app](https://blog-mui-future-ray.surge.sh/)

## ✨ Features

- 📱 **Fully Responsive** - Works seamlessly on mobile, tablet, and desktop
- 🎨 **Material-UI Design** - Clean, professional UI following Material Design principles
- 📝 **Create Posts** - Dialog-based post creation with form validation
- 🔄 **State Management** - Zustand for efficient state handling
- 🏷️ **Tag System** - Posts with tags for better organization
- ⚡ **API Integration** - Fetches posts from DummyJSON API
- 🎯 **TypeScript** - Type-safe code for better developer experience

## 🛠️ Tech Stack

- **React** - UI library
- **TypeScript** - Type safety
- **Material-UI (MUI)** - Component library
- **Zustand** - State management
- **React Hooks** - useState, useEffect
- **DummyJSON API** - Mock data for posts
